What the active forks of `unclebob/uml-viewer` added, what we took on
`feat/upstream-sync-2026-11`, and what is still on the table.

## Upstream

`upstream/master` moved from `79cc1ef` to `f65dafe`:

- Native TypeScript, Rust, and Python scanners (`graph-*` + `source-*`),
  `:sources` multi-root scans, and `merge-scans` for TS `invoke` → Rust
  command links.
- CRAP and mutation snapshots joined by class id, function-weighted
  parent grades, and honest "not measured" red.
- UI/metrics fixes from commits `650abbc` and `f65dafe`.
- PR #13 (`PleaseWorld`, still open upstream): NodeNext `.js` import
  specifiers now resolve to their `.ts` source. **Ported**, with its
  regression spec.

The merge keeps the fork's companion detach, Pi support, proposal
persistence, policy violation rules, Python measurement bridge, and CI.

## Still worth considering

1. **Browser/PR review** (`joshsmoore`): the web renderer is in (`--web`,
   `docs/web-viewer.md`); branch/PR diff highlighting and relationship filters
   remain. They need a design pass over `branch-diff` and the `--pr` argument.
2. **PHP scanner** (`heilmich`): port if a PHP project needs it; vendor
   `nikic/php-parser` or require `composer install`.
3. **Facts-file language** (`Cjewett`): useful for a language that already
   has a parser elsewhere; it needs a revisit against the current tree.
4. **Load an existing IR at startup** (`Noodle-cpp`): small UX change;
   it conflicts with the "wait for the companion" default.
5. **Go mutation/coverage** is now available through `tools/go-metrics`;
   Kotlin/C#/Ruby/Haskell metrics still need their own tools.
6. **Go interface/embedding edges** (`Conte777`): **done** — package-level
   `:implements` and `:inheritance` edges, with single-method interfaces
   excluded to avoid `Error`/`String` noise.
7. **Claude Code companion and Ruby/TS metric hooks** (`justinleveck`,
   `mariano-aguero`): useful when those runtimes are already part of the
   examined project; the Pi/Grok companion covers this repo today.
